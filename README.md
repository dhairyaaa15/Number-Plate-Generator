<h2>Description</h2>
<p>This project is a Gujarat Number Plate Generator built using Python's <code>tkinter</code> library. It allows users to generate vehicle number plates for the state of Gujarat, India, based on their personal and vehicle details.</p>

<h2>Features</h2>
<ul>
    <li>User input validation</li>
    <li>Number plate generation</li>
    <li>Data submission and storage</li>
    <li>Help and About sections</li>
</ul>

<h2>Installation</h2>
<ol>
    <li>Clone the repository:
        <pre><code>git clone https://github.com/dhairyaaa15/gujarat-number-plate-generator.git</code></pre>
    </li>
    <li>Navigate to the project directory:
        <pre><code>cd gujarat-number-plate-generator</code></pre>
    </li>
    <li>Run the application:
        <pre><code>python main.py</code></pre>
    </li>
</ol>
